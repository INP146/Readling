# Readling v0.2.0 发布说明

## 主要变更

- **EPUB 正文支持数学公式**。可排版的 MathML 和带 `\(…\)`、`\[…\]` 或 `$$…$$` 定界符的 TeX 会显示为公式。行内公式随正文排版，独立公式居中显示，过宽时会缩小以适应正文。无法排版的公式保留为文字。
- **EPUB 表格按阅读宽度排版**。空间充足时按列对齐，数字列靠右。较宽的表格会逐格换行，滚动和分页模式都适用。表格里的文字仍可搜索、选中查词或翻译，书内链接也能照常跳转。
- **修正 EPUB 的列表和段落样式**。有序列表支持字母、罗马数字和自定义起始编号，无序列表支持不同项目符号或隐藏标记。正文也会显示段间分隔线、嵌套引号和定义列表。
- **新增“设置 › 关于 › 数据与升级”**。可查看应用与数据版本、升级记录、书籍正文更新进度和备份占用。单本书更新失败时，可继续读旧正文，也可在此重试。

## 安装与重签

Release 提供未签名的真机安装包 `Readling-0.2.0.ipa`（Build `2`，Bundle ID `com.inp146.readling`，内置核心词典 `dict-2026.11.18.1`，支持 iOS 26.0+）及校验文件 `SHA256SUMS`。

- **自签工具**：将 `Readling-0.2.0.ipa` 导入 AltStore、SideStore、Feather 或 Sideloadly 等工具签名安装。
- **完整性校验**：在同一目录运行 `shasum -a 256 -c SHA256SUMS`（Linux 用 `sha256sum -c SHA256SUMS`）。

## 升级与兼容

- **覆盖安装**。使用与 v0.1.0 相同的签名证书和 Bundle ID（`com.inp146.readling`）直接覆盖安装，请勿先卸载。书籍、阅读进度、生词及复习记录、阅读和查词设置、翻译及 AI 服务配置、已下载的词典包和本机钥匙串中的 API Key 都会保留。词典包格式未变，无需重新下载或重新填写 API Key。
- **首次启动自动迁移书库**。书库格式从 2 升至 3，已保存的原书文件无需转换或重新导入。对保留了原书的书籍，应用会在后台自动更新正文，并换算阅读位置及生词在原文中的位置。打开还在等待更新的书时，会优先处理该书。升级前的旧书库文件会自动备份。
- **不支持带数据降级**。迁移完成后，v0.1.0 无法打开新版书库，覆盖装回旧版也不会恢复迁移前的书库。v0.1.0 之前的开发版旧书库格式不在本次迁移范围内。
