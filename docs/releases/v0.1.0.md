# Readling v0.1.0 发布说明

## 主要变更

- 可离线**导入无 DRM 的流式 EPUB 和 TXT**，也可从书架选择“导出书籍”，通过系统分享面板保存或分享。EPUB 重新打包并保留目录、样式表、字体和插图等资源，TXT 按原文件内容导出。
- **阅读时可切换滚动和分页**，分页有仿真、覆盖、平移和无动画四种方式。可调整字体、字号、间距、日夜配色和背景纹理，支持目录跳转、书内搜索、脚注链接、自动翻页或滚动，并记住阅读位置。
- **长按或双击单词即可查词**，拖动选区可查短语。内置约 15 万条 ECDICT 离线英汉词条，支持词形还原。单词卡可朗读、收藏和展开更多义项。在“设置 › 词典”可按需下载扩展词汇、八个学科包或人名地名包，下载后可离线查词，也可更新或删除扩展包。
- **词典查不到时，单词卡可直接显示简体中文译文**。默认使用 Apple 本机翻译，下载语言包后可离线使用。也可自行配置 DeepL（含 DeepLX）或 OpenAI 兼容、Claude、Gemini 接口的 AI 服务。AI 可结合原句解释词典未收录的单词。联网服务不可用或在返回结果前失败时，会尝试回退到本机翻译。
- **生词本支持闪卡和间隔复习**。可收藏单词或表达，保留原句和已有的释义或译文。生词按原形去重，支持搜索、按书筛选和跳回原文。答“记住了”会逐步拉长复习间隔，答“还不熟”则会在本轮再练一次，次日再复习。

## 安装与重签

Release 提供未签名的真机安装包 `Readling-0.1.0.ipa`（Build `1`，Bundle ID `com.inp146.readling`，内置核心词典 `dict-2026.11.18.1`，支持 iOS 26.0+）及校验文件 `SHA256SUMS`。

- **自签工具**：将 `Readling-0.1.0.ipa` 导入 AltStore、SideStore、Feather 或 Sideloadly 等工具签名安装。
- **完整性校验**：在同一目录运行 `shasum -a 256 -c SHA256SUMS`（Linux 用 `sha256sum -c SHA256SUMS`）。

## 升级与兼容

需要 iOS 26.0 或更高版本。导入的书籍、阅读进度、生词及复习进度、阅读设置和已下载的词典包均保存在本机。翻译服务的 API Key 保存在本机钥匙串中。使用联网翻译时，选中的文字会发给所选服务，部分请求还会附带所在句子。

日后升级时，用同一张签名证书和相同的 Bundle ID（`com.inp146.readling`）直接覆盖安装，即可保留上述数据和 API Key。请勿先卸载旧版。
